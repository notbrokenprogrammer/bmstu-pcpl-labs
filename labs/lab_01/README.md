# Основные конструкции Python

Лабораторная работа по курсу «Парадигмы и конструкции языков программирования».

На примере работы с коэффициентами уравнения рассматриваю разные способы организации программы: функции, отдельный класс и обработчик в модуле.

| Файл | Назначение |
| --- | --- |
| [root_main.py](root_main.py) | Точка входа, получение коэффициентов и запуск трёх вариантов |
| [models.py](models.py) | Класс `ObjectRoot`, хранение коэффициентов и результатов |
| [handlers.py](handlers.py) | Отдельная функция обработки коэффициентов |

## Запуск

Нужен Python 3.10 или новее. Из корня репозитория:

```bash
cd labs/lab_01
python3 root_main.py 1 -2 1
```

Три числа — коэффициенты `a`, `b`, `c`. Без аргументов программа запрашивает их при запуске каждого варианта:

```bash
python3 root_main.py
```
